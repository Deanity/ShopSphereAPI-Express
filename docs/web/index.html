ShopSphere API Reference

Production-grade RESTful e-commerce backend built with Express.js, TypeScript, Mongoose, Xendit payment integration, and RajaOngkir shipping calculation.

Base URL
http://localhost:5000/api/v1
Authentication
Bearer <JWT Access Token>

1. Authentication

POST /api/v1/auth/register PUBLIC

Register a new customer account and return access token.

FieldTypeDescription
name*stringFull user name (e.g. Budi Santoso)
email*string (email)Valid unique email address
password*string (min 8)Account password (hashed with bcrypt)
201 Created
JSON
{
  "success": true,
  "message": "Registration successful",
  "data": {
    "user": {
      "_id": "64d3f1a0e1c2b3a4f5e6d7c8",
      "name": "Budi Santoso",
      "email": "budi@example.com",
      "role": "customer"
    },
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
cURL
curl -X POST http://localhost:5000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name": "Budi Santoso", "email": "budi@example.com", "password": "secretpassword123"}'
POST /api/v1/auth/login PUBLIC

Authenticate user credentials and set httpOnly refresh cookie.

FieldTypeDescription
email*stringUser account email
password*stringUser account password
200 OK
JSON
{
  "success": true,
  "message": "Login successful",
  "data": {
    "user": { "_id": "64d3f1a0e1c2b3a4f5e6d7c8", "name": "Budi Santoso", "role": "customer" },
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
cURL
curl -X POST http://localhost:5000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "budi@example.com", "password": "secretpassword123"}'
POST /api/v1/auth/refresh-token COOKIE

Issue a new 15-minute access token using refreshToken cookie.

200 OK
JSON
{ "success": true, "message": "Token refreshed", "data": { "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." } }
POST /api/v1/auth/logout BEARER TOKEN

Log out current user session and clear refreshToken cookie.

200 OK
JSON
{ "success": true, "message": "Logged out successfully", "data": null }

9. Payments (Xendit Webhook)

POST /api/v1/payments/webhook WEBHOOK TOKEN

Xendit Invoice callback handler. Automatically updates paymentStatus to PAID, decrements product stock, and triggers customer notifications upon payment confirmation.

Header / FieldTypeDescription
x-callback-token*stringXendit Webhook Security Token Header
id*stringXendit Invoice ID
status*stringPAID | EXPIRED
200 OK
JSON
{ "success": true, "message": "Webhook processed successfully", "data": null }
